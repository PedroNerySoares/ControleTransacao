Controle de Transação 
===
  ## Sobre Projeto
  #### Desafio oferecido pela Alura, Uma aplicação que possibilita importação e visualização de transações bancárias. 
  
  <br>  
  
##  Funcionalidades:
- Controle de Usuário;
- Envio de email informando senha inicial do usuário recem cadastrado;
- Importação de arquivo de extensão CSV e XML;
- visualização das Transações importadas, Filtrando por data;
- Visualização de Transações consideradas suspeitas;
